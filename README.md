# Bubloo Nexus

Bubloo Scientist — Complete Website UI Redesign

Redesign and modernize the entire Bubloo Scientist website into a premium, futuristic, responsive science-and-technology platform.

Reference Website

Use the existing website as the primary content/reference source:

https://www.bublooscientist.com/

The current website contains:

Science education and knowledge

Physics, Chemistry and Biology content

Mathematics and Computer/Technology content

Science discoveries and educational resources

Blogs

Quizzes

Creative projects

Team information

Chatbot

Community/WhatsApp channel

Contact section

Personal/business projects

Preserve the important existing content and information, but completely modernize the visual design, layout, navigation, spacing, typography, components and user experience.

Design Reference

The Figma prototype provided by the client is the visual direction:

https://www.figma.com/proto/hoW7v7K3XuDKmPQ2UPML7j/Bubloo-Scientist-New-UI

Use the Figma design as inspiration/reference for the new UI structure and visual language.

Do NOT simply recreate the old website.

The goal is to make Bubloo Scientist feel like a real modern science-tech platform, rather than a traditional school/blog website.

Check animations.
